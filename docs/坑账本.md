# 坑账本

## 2026-08-17 手机菜单点了没反应

顶栏用了毛玻璃效果（半透明 + 背景模糊）。带这种效果的元素会把它内部的全屏弹窗「关」在自己里面——抽屉菜单本来写在顶栏里面，结果只能撑到顶栏那么高，看起来就是点了没反应、顶上多了一条白边。

**现在的处理**：抽屉和它后面的灰色遮罩必须写在顶栏**外面**，不能塞回顶栏里。以后谁给顶栏加类似的视觉效果，也别把全屏弹层放进去。

## 2026-08-17 站上图片一律自己托管

早期为了快，站上 103 张图全是直接链客户旧站（`img.venco.com.hk` 和一个 `workers.dev` 临时域名）。旧站一改版、清图片目录或换域名，新站就整片开天窗，加载快慢也完全看对方服务器。

**现在的处理**：图片全部下载到 `public/assets/img/`，数据文件里只写 `/assets/img/xxx`。以后新增图片同样先下载再用，不要直接贴外站链接。补图的脚本留在 `scripts/fetch-images.mjs`，可重复执行（已下载的会跳过）。

## 2026-08-17 关于页配图写在数据里，不写死在页面上

客户反馈「白底一堆字」不好看，关于页改成了图文交错。配哪张图、配什么小标题存在 `src/data/site.json` 的 `aboutBlocks` 里，中英文各一份。

**为什么**：以后客户想换图换标题，改 json 就行，不用动页面代码。`aboutBlocks` 按顺序和 `about` / `aboutEn` 的段落一一对应，删段落时记得同步删对应那条。
