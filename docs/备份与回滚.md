## 怎么回滚

**只想看看旧版长什么样**（不影响现在的代码）：

```bash
git worktree add /tmp/venco-old stable-pre-illustration
```

**线上出问题，紧急恢复到某个稳定点**（重新构建部署旧版）：

```bash
git stash -u && git checkout stable-pre-illustration && npm run deploy
```

看完/修完回来：`git checkout codex/vaccine-illustration-preview && git stash pop`

**Cloudflare 层面秒回滚**（不动代码，直接切回上一个部署版本）：

```bash
npx wrangler rollback
```

## 规矩

- 每次大改版（整页重做、架构调整）**之前**，先打一个 `stable-*` 标签并推送 GitHub，再动手。
- 标签只增不删；`~/Backups/` 的压缩包每次大版本手动加一份，别覆盖旧的。
